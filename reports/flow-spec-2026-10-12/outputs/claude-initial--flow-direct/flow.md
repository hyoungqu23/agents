# 사용자 흐름 명세: Personal reading notes

직접 입력(SRC-001)만 근거로 작성했다. 상위 PRD/문제 정의 문서는 없으며(입력에 "No prior documents exist"), 가짜 의존성은 만들지 않았다. 별도 검토(review) 결과는 제공되지 않았다. 이 문서는 독립 gate 통과나 구현 승인이 아니다.

## 범위와 소스 앵커

입력에 FR/AC ID가 없어 문장 단위 앵커를 사용한다.

| 앵커 | 원문 요지 |
| --- | --- |
| SRC-001#A1 | 기존의 정확히 일치하는(exact) 태그를 선택한다 |
| SRC-001#A2 | 해당 태그에 저장된 노트만 본다 |
| SRC-001#A3 | 노트를 연다 |
| SRC-001#A4 | 빈 결과와 조회 실패는 눈에 띄게 달라야 한다 |
| SRC-001#A5 | 실패 시 다른 태그를 선택할 수 있다 |
| SRC-001#C1 | 개인 용도; 태그와 노트는 이미 존재한다 |
| SRC-001#C2 | 제외: 편집, 공유, 새 인증, 저장소 설계, 속도 목표 |

- 역할: 단일 개인 사용자(SRC-001#C1). 다중 역할·권한 흐름 없음.
- DEC-001: 편집·공유·신규 인증·저장소 설계·속도 목표는 범위 밖이다 (SRC-001#C2, 사용자 명시).
- EV-001: 태그와 노트가 이미 존재한다고 입력이 보고한다 (SRC-001#C1). 독립 검증하지 않았다.

## FLOW-001: 태그로 노트 조회 후 열기

앵커: A1, A2, A3, A4, A5. 행위자: 사용자. 진입 조건: 읽기 노트 기능 진입, 기존 태그가 존재함(EV-001).

| 행동 / 조건 | 관찰 가능한 결과 | 다음 단계 / 종료 | 근거 |
| --- | --- | --- | --- |
| 기존 태그 중 하나를 정확히 선택 | 해당 태그의 조회가 시작됨 | 조회 결과 분기 | A1 |
| 조회 성공, 노트 ≥ 1 | 선택한 태그에 저장된 노트만 목록으로 표시 | 노트를 열거나 다른 태그 선택 | A2 |
| 조회 성공, 노트 0건 (빈 성공) | "이 태그에 노트 없음"을 뜻하는 상태가 표시되며 실패 표시와 구별됨 | 다른 태그 선택 | A4 |
| 조회 실패 | 실패임을 알리는 상태가 표시되며 빈 결과 표시와 구별됨 | 다른 태그 선택 (FLOW-002) | A4, A5 |
| 목록에서 노트 선택 | 해당 노트가 열림 | 노트 보기; 종료 또는 목록/태그 재선택 | A3 |

- 빈 결과와 실패는 서로 다른 상태이며, 사용자가 어느 쪽인지 구분할 수 있어야 한다(A4). 구체적 표현·시각 형태는 정하지 않았다(디자인 탐색 영역).
- 태그가 "존재한다"는 전제(C1) 때문에 빈 결과는 예외적 상태일 수 있으나, 입력이 명시적으로 요구하므로 흐름에 남긴다.

## FLOW-002: 조회 실패 후 다른 태그 선택

앵커: A5. 진입: FLOW-001에서 조회 실패.

| 행동 / 조건 | 관찰 가능한 결과 | 다음 단계 / 종료 | 근거 |
| --- | --- | --- | --- |
| 실패 상태에서 다른 태그 선택 | 새 태그로 조회 시작 | FLOW-001 재진입 | A5 |
| 실패한 같은 태그를 다시 시도 | 입력에 없음 | 미정 | OD-001 |

## 열린 결정 / 가정

- OD-001: 실패 후 같은 태그 재시도 제공 여부, 자동 재시도 여부. 입력은 "다른 태그 선택"만 명시. 영향: FLOW-002의 분기. 차단 여부: 비차단(명시된 경로는 설계 가능). 재검토 조건: 재시도 요구가 제기될 때. 임의로 정책을 만들지 않았다.
- OD-002: 노트를 연 뒤 돌아가는 방식(목록 복귀 등)과 노트가 열리는 위치. 입력 미명시. 영향: FLOW-001의 종료/재진입. 비차단.
- OD-003: 조회 "실패"의 범위(저장된 데이터 읽기 오류 등)와 노트 열기 자체의 실패 처리. 입력은 조회 실패만 언급. 노트 열기 실패 흐름은 미포함. 비차단.
- AS-001: "exact tag"는 목록에서 기존 태그를 고르는 방식이라 가정(자유 입력 철자 오류 처리는 다루지 않음). 이유: "choose an existing" 표현. 영향: 존재하지 않는 태그 입력 분기 유무. 확인: 사용자에게 선택 방식 확인. 미검증.

## 커버리지

| 앵커 | 흐름 | 비고 |
| --- | --- | --- |
| A1, A2, A3 | FLOW-001 | 포함 |
| A4 | FLOW-001 | 빈 성공 vs 실패 구분 |
| A5 | FLOW-001, FLOW-002 | 재시도는 OD-001 |
| C1, C2 | 범위/제약 | 비상호작용 제약 (DEC-001, EV-001) |

미포함: 노트 열기 실패, 존재하지 않는 태그 입력(AS-001), 노트 열람 후 이동(OD-002, OD-003).

## 상태와 디자인 인계

상태: `needs_decision` — 비차단 OD 3건과 미검증 AS 1건이 남아 있으나 명시된 핵심 흐름은 설계 탐색이 가능하다. 시장/수요 검증은 개인 용도라 범위 밖이다.

디자이너가 탐색 가능한 것: 태그 선택 UI 형태, 노트 목록/열람 배치, 빈 상태와 실패 상태의 구별 표현(둘이 달라야 한다는 제약 A4 유지). 제품 결정이 필요한 것: OD-001~003, AS-001. 시각 변형 선택, 프로토타입, 구현, commit, 게시는 수행하지 않았다.
