# 사용자 흐름: 기존 태그로 읽기 노트 찾기

## 범위와 입력 상태

- 범위: FR-001–FR-003, AC-001–AC-006 전체. 행위자는 기존 읽기 노트와 정확한 기존 태그를 가진 개인 한 명이다(PRD 사용자 절; DEC-002). 새 역할은 가정하지 않는다.
- 상위 문서 `prd.md`(revision 1, `ready_for_review`)와 `problem.md`를 실제로 읽었고, 위 sha256 접두는 이 작성 시점에 계산한 값이다. 독립 PRD 검토(prd-gate)는 제공되지 않았고 수행하지 않았다. 이 흐름은 검토 판정이나 구현 승인이 아니다.
- 제외: 태그 편집, 팀 공유, 새 인증, 정량 속도 목표(DEC-002). 레이아웃·아키텍처·저장 방식은 정하지 않는다(DEC-004). 이 문서도 화면 배치를 정하지 않는다.
- 미해결 제품 결정(OD)은 없다(DEC-005). AS-001(기존 노트·태그·저장된 내용을 읽을 수 있다는 가정)은 검증되지 않았고, 흐름 설계에는 비차단이다. 실제 데이터 접근은 확인하지 않았다.
- 재시도, 권한, 오류 종류별 정책은 PRD가 정하지 않았으므로 이 흐름에도 넣지 않는다(AC-004 설명).

## FLOW-001 — 기존 태그 선택과 결과 확인

- 지원: FR-001, AC-001, AC-002 / GOAL-001 / DEC-001
- 행위자·진입: 개인 사용자가 태그 조회 화면에 들어온다. 선택 가능한 기존 태그가 있다.

| 행동 또는 조건 | 사용자가 구분할 수 있는 결과 | 다음 단계 또는 종료 | 근거 |
| --- | --- | --- | --- |
| 기존 태그 T 선택, 조회 성공, T를 가진 노트 존재 | 결과에 T가 달린 모든 기존 노트가 있고 T 없는 노트는 없다 | FLOW-002로 노트를 열거나 다른 태그 선택 | AC-001 |
| 결과를 보는 중 다른 기존 태그 U 선택, 조회 성공 | 결과가 U의 노트 집합으로 바뀌고 T에만 속한 노트는 남지 않는다. 열려 있던 노트 선택은 해제된다(아래 참고) | U 기준으로 FLOW-002/003/004 | AC-002 |
| 조회 성공 + 해당 노트 없음 | FLOW-003 | FLOW-003 | AC-005 |
| 조회 실패 | FLOW-004 | FLOW-004 | AC-006 |

참고: "T에서 U로 바꿀 때 열린 노트를 닫는다"는 AC-002의 "T에만 해당하는 노트가 U의 결과로 남지 않는다"를 따르기 위한 흐름 해석이며 새 사용자 결정이 아니다.

## FLOW-002 — 결과 노트의 저장된 내용 열기

- 지원: FR-002, AC-003, AC-004 / GOAL-002 / DEC-001
- 진입: FLOW-001에서 성공한 조회의 결과가 하나 이상 표시되어 있다.

| 행동 또는 조건 | 사용자가 구분할 수 있는 결과 | 다음 단계 또는 종료 | 근거 |
| --- | --- | --- | --- |
| 결과 노트 N 선택, 내용 읽기 성공 | N의 저장된 내용이 열린다. 다른 결과 노트의 내용이 아니다 | 결과로 돌아가 다른 노트를 열거나 태그를 바꾼다 | AC-003 |
| 결과 노트 N 선택, 내용 읽기 실패 | "N의 내용을 열지 못했다"는 상태. 열기 성공이나 태그 조회 결과 없음으로 보이지 않는다 | 결과로 돌아가 다른 노트 선택 가능. 재시도 방식은 정하지 않음 | AC-004 |

## FLOW-003 — 조회 성공 후 결과 없음

- 지원: FR-003, AC-005 / GOAL-003 / DEC-003
- 진입: 선택한 기존 태그를 가진 노트가 없고 조회가 성공했다.

| 행동 또는 조건 | 사용자가 구분할 수 있는 결과 | 다음 단계 또는 종료 | 근거 |
| --- | --- | --- | --- |
| 조회 성공, 일치 노트 0개 | 선택한 태그의 결과가 없다는 표시. 조회 실패 표시가 아니다 | 다른 태그 선택(FLOW-001) | AC-005 |

## FLOW-004 — 조회 실패

- 지원: FR-003, AC-006 / GOAL-003 / DEC-003
- 진입: 선택한 태그의 조회가 실패했다.

| 행동 또는 조건 | 사용자가 구분할 수 있는 결과 | 다음 단계 또는 종료 | 근거 |
| --- | --- | --- | --- |
| 조회 실패 | 조회 실패 표시. FLOW-003의 결과 없음 표시와 눈으로 구분되며, "해당 노트가 없다"는 확정 결과로 제시하지 않는다 | 다른 태그 선택(FLOW-001). 재시도 정책은 정하지 않음 | AC-006 |

## 설계 인계

- 탐색 가능: 태그 선택·결과·내용 열기·빈/실패 상태의 구조, 위계, 상호작용 방식.
- 제품 선택이 필요한 항목: 없음(OD 없음). 정렬, 재시도, 오류 유형별 문구, 권한/동시 변경은 PRD가 정하지 않았으므로 데모에서도 정책으로 만들지 않는다.
- 데모의 한계: 시연 화면은 샘플 노트·태그로 조회 성공/없음/실패/내용 열기 실패를 모의한다. 실제 데이터를 읽지 않는다.
