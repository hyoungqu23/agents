# 내부 문서 검토에서 의도한 리비전 열기 — 사용자 흐름 명세

## 범위와 읽는 방법

기존 내부 동료가 검토 문서에 접근하고 전달자가 의도한 리비전을 여는 결과를 다룬다. 문서 담당자는 검토 문서를 전달하는 역할이고, 수신자는 문서를 열어 검토하는 역할이다. 담당자라는 이유로 리비전 정책·권한 정책의 결정 권한까지 부여하지 않는다. FR-001–FR-004 및 AC-001–AC-004가 모두 범위에 포함된다. [SRC-003 §2–5]

`needs_decision`: 정상 열기는 기대 리비전과 허용 조건이 주어진 경우에만 명세할 수 있다. OD-004·OD-005가 핵심 분기를, OD-006이 실패 후 처리를 막고 있어 전체 흐름은 확정되지 않았다. 질문 없이 작성한 조건부 초안이며, 독립 검토 통과나 구현 승인으로 해석하지 않는다. 별도 사전 검토 보고서는 제공되지 않았다. problem.md의 `ready_for_review`는 문제 정의의 상태이며 PRD나 이 흐름의 검토 판정이 아니다.

이 문서의 SRC 번호는 위 파일을 가리킨다. EV·DEC·OD·FR·AC 번호는 PRD의 기존 의미를 그대로 참조한다. PRD 안의 SRC-003은 당시 사용자 요청이며, 이 문서의 SRC-003과 구별한다. 새 가정(AS)이나 제품 결정을 만들지 않았다.

## 유지하는 근거와 제약

- EV-000–EV-003: 합성 입력이다. 주간 PDF 전달, 원본 변경, 과거 사본 보관 가능성, 파일명 리비전 및 교체 첨부파일이라는 현재 우회책을 보고한다. 지난주 **12명 중 4명**이 오래된 버전을 열었다는 수치는 독립 검증되지 않았고 과거 기준선도 없다. 반복 빈도·개선율·비용·매출·손실 시간·유지율 영향으로 확장하지 않는다. [SRC-001 서두 및 `User-provided context`; SRC-003 §1]
- DEC-001: 기존 내부 사용자만 대상이다. 익명 공유와 새 로그인 구현은 범위 밖이다. 기존 계정 보유가 모든 문서의 접근 권한을 뜻하지 않는다.
- DEC-002: 만료·복사/내보내기·철회는 미결정이다. 무제한 허용이나 일괄 금지를 기본값으로 삼지 않는다.
- DEC-003: 첫 성공 관찰은 의도한 리비전과 실제 열린 리비전의 일치다. 비교는 검토 관찰 기준이며 제품 내 리비전 표시, 기록 수집 기능이나 분석 도구 요구를 추가하지 않는다.
- DEC-004·DEC-005는 각각 이전 문제 정의와 PRD 작성의 산출물 범위로 보존한다. 현재 요청은 흐름 문서 작성이다. UI·API·데이터베이스·기술 구조·출시 일정은 정하지 않는다. 링크나 특정 전달 방식도 확정하지 않는다. [SRC-003 §3, §6; SRC-004]

## FLOW-001 — 허용된 내부 수신자의 정상 열기

**연결:** GOAL-001·GOAL-002, FR-001/AC-001, FR-004/AC-004, DEC-001·DEC-003.  
**행위자와 진입:** 기존 계정을 가진 내부 수신자. 해당 검토의 의도한 리비전과 문서 접근 허용 조건이 정해진 상황을 전제로 한다. 조건을 정하는 제품 절차는 OD-004·OD-005 때문에 아직 명세할 수 없다.

| 단계·행동 또는 조건 | 관찰 가능한 결과 | 다음 단계 또는 종료 |
| --- | --- | --- |
| 1. 수신자가 기존 로그인 계정을 이용하는 조건에서 대상 문서 열기를 시도한다. | 접근 요청 대상은 해당 검토 문서다. 새 로그인 체계를 완료 조건으로 요구하지 않는다. | 2. 계정 확인 화면이나 인증 전환 방식은 지정하지 않는다. |
| 2. 기존 내부 사용자이고 문서 접근이 허용된다. | 의도한 리비전 열기로 진행할 수 있다. | 3. 허용 여부가 정해지지 않았다면 OD-005로 이 분기 확정 유보. |
| 3. 의도한 리비전이 정상적으로 열린다. | 수신자가 해당 문서 내용을 열어 검토할 수 있다. 실제 열린 리비전이 의도한 리비전과 일치하면 AC-001·AC-004의 결과를 충족한다. | 검토로 종료. 이후 원본 변경 후 재접근은 FLOW-002. |
| 4. 의도한 리비전이 열리지 않거나 다른 리비전이 열린다. | 의도한 리비전 열기 성공이 아니다. | 이용 불가·실패는 FLOW-005. 과거 PDF 이용은 FLOW-003. |

문서 담당자의 전달 행동은 기존 상황으로만 둔다. 새 공유 생성·발송·리비전 선택 조작을 요구사항으로 만들지 않는다. [EV-001·EV-003, OD-004]

## FLOW-002 — 전달 후 원본 변경과 재접근

**연결:** FR-002/AC-002, FR-001/AC-001, EV-001·EV-002, OD-004·OD-005.  
**행위자와 진입:** 이전에 검토 문서를 전달받은 내부 수신자. 전달 이후 원본이 변경되었다.

| 단계·행동 또는 조건 | 관찰 가능한 결과 | 다음 단계 또는 종료 |
| --- | --- | --- |
| 1. 수신자가 문서를 다시 열려고 한다. | 재접근 시점의 접근 허용 조건과 기대 리비전을 확인해야 하는 상황이다. 과거 접근 성공이 현재 권한을 보장하지 않는다. | 2. 보관한 PDF를 직접 여는 경우 FLOW-003. |
| 2. 변경 이후 어떤 리비전이 의도한 것인지 정해지지 않았다. | 열릴 리비전과 성공 여부를 아직 확정할 수 없다. 항상 최신 또는 전달 시점 고정 어느 쪽도 채택하지 않는다. | OD-004 결정 대기인 명세 분기. 사용자에게 대기 화면을 요구하는 뜻은 아니다. |
| 3. OD-004로 기대 리비전이 정해지고 접근도 허용된다. | 다시 연 실제 리비전이 합의한 기대 리비전과 일치하면 AC-002를 충족한다. | FLOW-001의 열기 결과를 거쳐 검토로 종료. |
| 4. 실제 열린 리비전이 기대 리비전과 다르다. | 파일이 열렸어도 AC-002 성공이 아니다. | 보관 사본이면 FLOW-003, 대체본·열기 실패 처리이면 FLOW-005. |
| 5. 재접근 시 접근 조건이 충족되지 않거나 만료·철회 경계에 걸린다. | 재접근 결과를 이전의 허용 상태로 단정할 수 없다. | FLOW-004 또는 FLOW-006. |

OD-004는 리비전 기준뿐 아니라 정하는 시점과 주체도 포함한다. 전달자에게 자동으로 정책 결정권을 배정하지 않는다.

## FLOW-003 — 보관한 과거 PDF 열기와 불일치 관찰

**연결:** FR-002/AC-002의 불일치 사례, EV-001·EV-003, DEC-003, OD-002·OD-004.  
**행위자와 진입:** 이전 내보내기 PDF를 보관한 수신자. 이 경로는 기존 우회책의 관찰이며 신규 기능이 사본을 관리한다는 뜻이 아니다.

| 단계·행동 또는 조건 | 관찰 가능한 결과 | 다음 단계 또는 종료 |
| --- | --- | --- |
| 1. 수신자가 보관한 PDF를 연다. | 보관된 파일의 리비전이 열린다. 원본 변경만으로 그 파일이 갱신됐다고 보지 않는다. | 2. |
| 2. 합의된 기대 리비전과 실제 열린 리비전을 대조한다. | 같으면 리비전 일치 관찰, 다르면 불일치 관찰이다. 과거 파일이라는 이유만으로 항상 불일치라고 단정하지 않는다. 기대 리비전 미정이면 판정 유보다. | 일치 시 관찰 종료. 불일치 시 AC-002 성공으로 판정하지 않고 3. |
| 3. 불일치한 파일·전달 경로를 확인한다. | 어떤 사본을 통해 불일치가 발생했는지 후속 관찰할 수 있다. 제품 내 자동 탐지·경고·로깅 요구는 아니다. | 관찰 종료. 수신자가 현재 문서 접근을 별도로 시도하면 FLOW-001 또는 FLOW-002. 자동 이동은 요구하지 않는다. |

리비전 대조와 경로 확인은 PRD §2·§7의 관찰 제안이다. 보관 파일의 자동 갱신·삭제·차단은 정해지지 않았다. 교체 첨부파일 재전달은 현재 우회책이지 새 제품의 복구 절차 확정이 아니다. 사본 생성·보관·이용 통제는 FLOW-006/OD-002에 남긴다.

## FLOW-004 — 접근 대상 구분과 접근 거부

**연결:** FR-003/AC-003, FR-001/AC-001 및 FR-004/AC-004의 권한 전제, DEC-001, OD-005.  
**행위자와 진입:** 이번 기능으로 문서 접근을 시도하는 사용자.

| 행동 또는 조건 | 관찰 가능한 결과 | 다음 단계 또는 종료 |
| --- | --- | --- |
| 익명 사용자 또는 기존 내부 사용자가 아닌 사용자가 접근한다. | 이번 기능으로 문서 내용을 열 수 없다. AC-003의 확정된 결과다. 차단 안내 방식은 정하지 않는다. | 해당 접근 시도 종료. 가입·초대·새 로그인 구축 흐름을 추가하지 않는다. |
| 기존 내부 사용자이며 해당 문서의 허용 대상이다. | 문서 열기로 진행할 수 있다. 계정 존재만으로 이 조건을 충족했다고 보지 않는다. | FLOW-001 또는 원본 변경 시 FLOW-002. |
| 기존 내부 사용자이나 해당 문서의 허용 대상이 아니다. | 정상 허용 경로로 진행시킬 수 없다. 문서별 판정 규칙과 구체 거부 결과는 OD-005로 유보한다. | 해당 분기의 명세 확정 대기. 권한 신청·관리자 승인·자동 재시도를 만들지 않는다. |
| 기존 내부 사용자의 문서별 허용 여부를 정할 수 없다. | 허용이나 거부 어느 결과도 임의로 확정하지 않는다. | OD-005가 해소되면 위 허용·비허용 분기로 구체화한다. |

익명 접근 차단은 보관된 로컬 PDF의 이용까지 차단한다는 뜻이 아니다. 기존 로그인 세션의 세부 동작도 입력에 없다.

## FLOW-005 — 의도한 리비전 이용 불가 또는 열기 실패

**연결:** FR-001/AC-001·FR-002/AC-002의 실패 경계, PRD §4 시나리오 5 및 §5, OD-006.  
**행위자와 진입:** 문서를 열거나 다시 여는 수신자. 의도한 리비전을 사용할 수 없거나 열기 작업이 실패했다.

| 행동 또는 조건 | 관찰 가능한 결과 | 다음 단계 또는 종료 |
| --- | --- | --- |
| 의도한 리비전을 이용할 수 없거나 열기가 실패한다. | 의도한 문서 내용을 열지 못했다. 성공 기준을 충족하지 않는다. 오류 안내 내용과 후속 행동은 미정이다. | OD-006으로 결과 안내·복구 경로 확정 유보. |
| 대체 리비전 제공 여부를 검토한다. | 자동 대체를 채택하지 않는다. 다른 리비전을 열어도 의도한 리비전 성공으로 간주할 수 없다. | 대체본 제공 여부와 이후 목적지는 OD-006 결정 후 정의한다. |
| 빈 콘텐츠 또는 빈 문서를 만난다. | 정상적으로 열린 빈 문서와 작업 실패를 같은 상태로 취급하지 않는다. 입력에 빈 문서의 취급이 없어 성공·실패 판정이나 안내를 새로 정하지 않는다. | PRD §5 및 OD-006에 따라 명세 유보. |

재시도 가능 여부·횟수·자동 재시도·취소 후 복귀·부분 성공 처리에 대한 근거가 없다. 임의의 복구 정책을 넣지 않으며 실패 후 목적지는 OD-006의 미해결 범위로 남긴다. 나중에 다시 열기를 허용하는 정책이 결정되면 FLOW-001/002와의 재진입 조건을 함께 정해야 한다.

## FLOW-006 — 만료·사본·철회 정책 경계

**연결:** DEC-002, OD-001–OD-003, PRD §5–7. 이 정책들의 구체 FR/AC는 아직 없다.  
**행위자와 진입:** 문서에 접근하거나 사본을 이용하려는 수신자. 아래 정책 상황이 적용될 때의 분기다. 철회를 수행하는 주체·권한은 제공되지 않아 새 역할을 만들지 않는다.

| 조건 또는 행동 | 아직 결정되지 않은 결과 | 연결·종료 또는 재진입 |
| --- | --- | --- |
| 링크 접근 방식을 선택하고 유효기간 경계에서 열기를 시도한다. | 만료 여부·조건에 따라 접근 가능 기간이 달라진다. 링크 자체와 영구 유효·자동 만료 모두 미확정이다. [OD-001] | 허용되는 조건이 결정되면 FLOW-001/002. 제한 시 결과와 후속 목적지는 결정 필요. |
| 문서를 복사·내보내거나 별도 사본을 보관·이용하려 한다. | 허용·제한 범위와 기존 사본에 대한 적용이 미정이다. 생성 가능·불가능 어느 쪽도 기본값으로 두지 않는다. [OD-002] | 과거 사본 관찰은 FLOW-003. 사본 조작의 완료·거부·후속 경로는 결정 필요. |
| 접근 철회 이후 문서를 열거나 다시 접근한다. | 어떤 접근이 가능한지, 이전 접근이나 사본에 어떤 영향이 있는지 미정이다. 즉시 차단·계속 허용을 선택하지 않는다. [OD-003] | 허용 경로와 제한 경로의 적용 조건·후속 결과 모두 결정 필요. |

## 수용 기준 연결 및 설계 인계

| 수용 기준 | 흐름과 다루는 결과 | 확정 한계 |
| --- | --- | --- |
| AC-001 / FR-001 | FLOW-001 정상 열기, FLOW-004 접근 조건, FLOW-005 열기 실패 | 기대 리비전 OD-004와 문서 권한 OD-005가 필요. 실패 세부 동작 OD-006 미정. |
| AC-002 / FR-002 | FLOW-002 변경 후 재접근, FLOW-003 과거 PDF 불일치, FLOW-005 실패 | 변경 후 기대 리비전 OD-004 미정. 불일치는 성공이 아님이 확정. |
| AC-003 / FR-003 | FLOW-004 익명·비내부 사용자 내용 접근 차단 | 차단 결과는 명시됨. 차단 안내 방식은 후속 설계 범위. |
| AC-004 / FR-004 | FLOW-001 기존 계정으로 허용 문서 열기, FLOW-004 허용 대상 분기 | 새 로그인 구현은 불필요한 완료 조건. 문서별 허용 규칙 OD-005 미정. |

모든 범위 내 AC를 위 흐름에 연결했다. 연결은 검증 통과를 뜻하지 않는다. 만료·사본·철회의 FR/AC 부재는 FLOW-006에서 드러내며, 분석 기능·측정 도구는 비요구사항이다.

| 열린 결정 | 영향을 받는 흐름·차단 범위 | 다시 다룰 조건 |
| --- | --- | --- |
| OD-001 링크 만료 여부·조건 | FLOW-006, 적용 시 FLOW-001/002의 접근 기간. 링크 방식 자체도 미확정. | 링크 접근을 검토하고 유효기간 동작을 정하기 전. |
| OD-002 복사·내보내기 제한과 범위 | FLOW-003/006의 사본 생성·보관·이용 결과. 기존 사본 통제는 확정 불가. | 사본 생성과 원본 변경 이후 이용 방식을 정하기 전. |
| OD-003 철회 후 접근 | FLOW-006 및 FLOW-002/004의 재접근 결과. | 접근 철회 요구사항과 수용 기준을 정하기 전. |
| OD-004 의도한 리비전의 기준·시점·주체 | FLOW-001/002/003/005의 기대 리비전과 성공 판정. 핵심 흐름 확정을 차단. | 변경 전후 재접근 사례의 기대 리비전을 정하기 전. |
| OD-005 문서별 허용 대상 규칙 | FLOW-001/002/004의 내부 사용자 허용·거부. 핵심 흐름 확정을 차단. | 내부 사용자별 허용·거부 사례를 확정하기 전. |
| OD-006 이용 불가·실패·대체 리비전 처리 | FLOW-005 및 FLOW-001/002의 실패 후 목적지, 빈 콘텐츠 관련 구체 결과. | 열기 실패·이용 불가 리비전의 수용 기준을 작성하기 전. |

결정 주체는 자료에 명시되지 않아 모두 미상으로 유지한다. 이 미결정들은 문서 저장을 막지 않지만 각 분기의 확정을 막는다. 현재 탐색 가능한 것은 조건이 주어진 정상 열기, 명시된 외부·익명 접근 차단, 리비전 일치·불일치의 관찰 결과다. 화면 구성과 표현은 후속 설계에서 탐색할 수 있지만, 그 과정에서 열린 정책을 기본값으로 확정해서는 안 된다.
