# 기존 태그 탐색 A/B

2026-10-14 · 탐색 산출물. 적용 스킬: 지정된 `prototype-explore`; 행동 근거는 `../flow.md` revision 1이다. `flow-spec`으로 흐름을 먼저 작성했다. 설계 대상은 이 작업공간의 개인 읽기 노트 태그 탐색 화면이며 운영 앱 구현 경로는 제공되지 않았다. 프로젝트 루트에 기존 DESIGN.md / design-system.md / DESIGN_SYSTEM.md, AGENTS.md / CLAUDE.md, 앱 스타일 또는 HTML이 없다. 따라서 로컬 디자인 제안으로 작성했으며 앱 전체 디자인 시스템으로 확정하지 않는다.

## 비교 질문과 열기

“태그·결과·내용을 한눈에 비교할 것인가, 단계마다 읽기에 집중할 것인가?”

- [A 열기](index.html?variant=A): 넓은 화면에서 태그 / 결과 / 내용의 3열 분할. 태그를 바꾸며 결과와 내용을 가까이 보는 구조다. 좁은 화면에서는 열을 쌓는다.
- [B 열기](index.html?variant=B): 태그 선택 → 결과 → 읽기 단계형. 결과로 돌아가기와 태그 다시 선택을 명시하고 한 화면의 주된 행동을 줄인다.

Opening mode: **direct file**. `index.html`을 직접 열 수 있도록 CSS, classic JavaScript, 샘플 데이터를 모두 인라인으로 작성했다. 외부 폰트·이미지·네트워크 요청·설치·서버가 없다. 기본값과 알 수 없는 variant는 A다. 링크의 variant는 새로 열 때도 해석된다. 하단 이전/다음은 두 변형을 순환하고 URL을 함께 바꾼다. back/forward는 popstate로 처리한다. 선택 태그·열린 노트·실패 시연 설정은 변형 변경 시 메모리에 유지되며 새로고침하면 초기화된다. 시연 초기화로 재생 가능하다.

화살표 전환은 편집 제어와 키보드를 사용하는 위젯 밖에서만 동작한다. 네이티브 제어의 방향키 동작은 가로채지 않는다. 하단 패널용 여백을 예약했다. 실제 겹침과 키보드 동작은 브라우저 검증이 필요하다.

## 실제 단계별 결과

1. `../flow.md`: FLOW-001–004, FR-001–003 및 AC-001–006 전체 연결.
2. `index.html`: 두 구조, 정상 결과·내용·빈 결과·조회 실패·내용 실패와 시연 초기화.
3. 사용자 요청의 명시적 B 선택에 따라 `prototype-promote`로 `../prototype/index.html`과 `../prototype/reference.md` 작성. 이 탐색 원본은 유지했다.

선택 근거: 이번 사용자 요청 “이번 합성 평가에서는 사용자가 B를 선택한 것으로 명시한다.” 선택 이유는 제공되지 않았다. B가 더 우수하다는 사용자 조사나 평가 결과는 없다.

## 시연 데이터와 행동

실제 노트를 받은 것이 아니므로 합성 샘플을 표시한다. 사유={n1,n2}, 디자인={n3,n4}, 기록={n1,n4}, 보관={}이다. 태그 문자열의 정확한 포함 관계로만 필터링한다. 시연 설정에서 조회/내용 읽기 실패를 각각 선택할 수 있다. 즉시 갱신하는 실패 제어는 평가 장치이며 실제 오류 원인·지연·재시도 정책이 아니다. 태그 다시 선택 및 결과로 돌아가기 역시 이 디자인의 탐색 제어다.

FLOW-001 / AC-001·002: 태그 선택과 정확한 집합 교체. FLOW-002 / AC-003·004: 노트의 샘플 저장 내용 또는 해당 노트 열기 실패. FLOW-003 / AC-005: 보관 태그의 성공한 0개. FLOW-004 / AC-006: 조회 실패와 결과 유무 미확정. AS-001의 실제 데이터 접근은 여전히 미확인이고 제품 정책 OD는 없다.

## 검증

실행: `node explore/verify.cjs` (프로젝트 루트). [verification.json](verification.json)에 Node VM과 최소 DOM 대역을 사용한 **26개 검사 통과**가 기록되어 있다. 실제 스크립트의 파싱·초기화, 샘플 정확 집합, 태그 교체, 노트별 본문, 두 종류 실패, 빈 결과, 초기화, 변형 선택·URL 처리·이력 핸들러·키 핸들러 로직, 외부 로딩 없음, B 추출 일치를 확인했다. DOM 대역 검사는 브라우저 클릭이나 실제 포커스 검증이 아니다.

[contrast.json](contrast.json)은 선언된 색상 토큰의 수학적 대비값이다. 본문 11.66:1, 보조 글자 5.43:1, 버튼 6.97:1, 오류 6.65:1, 포커스/표면 5.40:1. 실제 렌더링과 모든 조합의 접근성 적합성은 검증하지 않았다.

로컬 Google Chrome을 최종 파일 검증용 headless 모드로 시작하려 했으나 종료 코드 134로 실패했다. 디버깅 포트 연결도 실패했다. 파일을 브라우저에서 여는 단계에 도달하지 못했다. 설치나 외부 조회는 하지 않았다.

**미실행:** file:// 브라우저 실행, 375/768/1440 CSS px 시각 검사, 스크린샷, 실제 새로고침·뒤로/앞으로, Tab 포커스 순서·네이티브 방향키, 실제 콘솔/리소스 오류, reduced-motion 환경 확인, 실데이터 통합 및 사용자 평가.
