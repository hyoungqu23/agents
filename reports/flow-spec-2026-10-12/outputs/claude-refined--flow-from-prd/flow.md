# 내부 문서 검토에서 의도한 리비전 열기 — 사용자 흐름 명세

## 1. 범위와 입력 상태

**범위:** 기존 내부 사용자가 문서를 열 때 전달자가 의도한 리비전이 열리는지에 관한 흐름. 대상 역할은 문서 담당자(전달자)와 기존 내부 수신자이며, 대상 요구사항은 PRD의 FR-001–FR-004 / AC-001–AC-004다. [SRC-001]

**입력 신선도:** 지정된 PRD, 원자료, 문제 정의만 읽었다. 제공된 선행 검토(prd-gate 결과)는 없으므로 검토 통과 여부는 `unverified`이며, 이 문서는 게이트를 새로 수행하지 않았다. PRD 자체가 `needs_decision`이다. 외부 조회, 설치, commit, 게시는 하지 않았다. 질문 없이 초안을 작성하라는 요청에 따라 미결정 분기는 열어 두었다. [SRC-004]

**유지하는 결정과 근거 (PRD ID 그대로):**
- DEC-001: 기존 내부 사용자만 대상. 익명 공유와 새 로그인 구현은 범위 밖.
- DEC-002: 링크 만료, 복사·내보내기 제한, 접근 철회는 미결정.
- DEC-003: 첫 성공 관찰은 의도한 리비전을 여는지 여부. 임의 개선율 목표 없음.
- DEC-004/DEC-005: UI·데이터베이스 설계는 작성하지 않음.
- EV-002: 지난주 12명 중 4명이 오래된 버전을 열었다는 보고. 독립 검증이나 기준선은 없고 합성 입력이다(EV-000).
- EV-003: 기존 로그인 계정이 있다. 이것이 문서별 권한을 뜻하지는 않는다.

이 흐름은 화면, 전달 수단(링크/첨부/기타), API, 저장 구조를 정하지 않는다. "문서를 연다", "접근한다"는 수단과 무관한 사용자 행동이다.

## 2. 흐름

공통 용어: **의도한 리비전**은 OD-004가 정하기 전까지 값이 정해지지 않은 기준이다. 아래 흐름은 이를 "의도한 리비전(OD-004)"으로만 지칭하며 최신 리비전이나 전달 시점 고정 중 어느 쪽도 기본값으로 삼지 않는다.

### FLOW-001: 허용된 내부 수신자가 의도한 리비전을 연다

- **지원:** FR-001, FR-004 / AC-001, AC-004 · GOAL-001, GOAL-002
- **행위자:** 기존 내부 수신자 (전달자는 의도한 리비전을 지정하는 쪽이나, 지정 주체·시점은 OD-004 미결정이다)
- **진입 조건:** 의도한 리비전이 정해져 있고, 수신자가 기존 로그인 계정을 보유하며 해당 문서의 허용 대상이다.

| 행동 또는 조건 | 관찰 가능한 결과 | 다음 단계 또는 종료 | 요구사항 / 결정 |
| --- | --- | --- | --- |
| 수신자가 기존 계정으로 문서를 연다. | 새 로그인 체계를 거치지 않고 문서에 접근한다. | 리비전 확인으로 진행 | AC-004, DEC-001, EV-003 |
| 수신자가 허용 대상인지 판정된다. | 허용되면 열기가 진행된다. 허용 규칙은 미결정이다. | 허용: 다음 행 / 비허용: FLOW-005 | AC-001, OD-005 |
| 실제 열린 리비전을 의도한 리비전과 대조한다. | 일치하면 성공 관찰(DEC-003)이다. | 종료 | AC-001, DEC-003 |
| 열린 리비전이 의도한 리비전과 다르다. | 성공으로 판정하지 않는다. | 불일치 사례로 기록(제안)·종료 | AC-001, GOAL-001 |

- **재진입:** 이후 원본이 변경된 뒤 다시 열면 FLOW-002.
- **열린 지점:** 의도한 리비전의 선택 규칙(OD-004), 허용 대상 규칙(OD-005). 두 가지가 정해지기 전에는 AC-001 전체를 검증할 수 없다.

### FLOW-002: 원본 변경 후 재접근

- **지원:** FR-002 / AC-002 · EV-001, EV-002
- **행위자:** 기존 내부 수신자
- **진입 조건:** 전달 이후 원본 문서가 변경되었고, 수신자가 다시 문서에 접근한다.

| 행동 또는 조건 | 관찰 가능한 결과 | 다음 단계 또는 종료 | 요구사항 / 결정 |
| --- | --- | --- | --- |
| 수신자가 변경 후 다시 문서를 연다. | 어떤 리비전이 의도한 것인지는 OD-004에 달려 있다. 가능한 결과는 (a) 변경 후 리비전이 의도됨, (b) 전달 시점 리비전이 의도됨, (c) 기타 규칙이며 이 중 선택된 것이 없다. | OD-004 해소 전에는 기대 리비전을 지정하지 않음 | AC-002, OD-004 |
| OD-004로 정해진 의도한 리비전과 실제 열린 리비전이 일치한다. | 성공 관찰 | 종료 | AC-002, DEC-003 |
| 일치하지 않는다. | 성공으로 판정하지 않는다. | FLOW-003(보관 파일 경로) 또는 FLOW-006으로 원인 구분 | AC-002 |

- **열린 지점:** OD-004가 이 흐름의 기대 결과를 막는다. 흐름의 구조(재접근 → 대조 → 판정)는 확정이지만 기대값은 미확정이다.

### FLOW-003: 수신자가 보관한 이전 PDF를 연다

- **지원:** AC-002의 불일치 분기 · EV-001, EV-003
- **행위자:** 기존 내부 수신자
- **진입 조건:** 수신자가 이전에 받은 내보내기 PDF를 보관하고 있고 그 파일을 연다.

| 행동 또는 조건 | 관찰 가능한 결과 | 다음 단계 또는 종료 | 요구사항 / 결정 |
| --- | --- | --- | --- |
| 수신자가 보관된 PDF를 연다. | 파일의 리비전이 의도한 리비전과 다르면 불일치이고 성공이 아니다. | 어떤 파일·전달 경로로 열었는지 확인(관찰 제안) | AC-002, 시나리오 3 |
| 보관 사본의 이용을 통제할지 여부 | 정해지지 않았다. 자동 갱신, 삭제, 차단 중 어느 것도 요구로 확정하지 않는다. | 열린 상태로 유지 | OD-002, DEC-002 |

- **구분:** 새 접근 경로의 성공(FLOW-001/002)과 이미 존재하는 사본의 통제는 별개다. 사본 통제 범위는 OD-002가 정한다.

### FLOW-004: 익명 또는 내부 사용자가 아닌 사람의 접근 시도

- **지원:** FR-003 / AC-003 · GOAL-002, DEC-001
- **행위자:** 익명 사용자 또는 기존 내부 사용자에 해당하지 않는 사용자
- **진입 조건:** 이 기능으로 문서 접근을 시도한다.

| 행동 또는 조건 | 관찰 가능한 결과 | 다음 단계 또는 종료 | 요구사항 / 결정 |
| --- | --- | --- | --- |
| 해당 사용자가 문서 접근을 시도한다. | 문서 내용을 열 수 없다. | 종료 | AC-003, DEC-001 |
| 차단 사실을 알리는 방식 | 지정하지 않는다. 안내 문구, 로그인 유도 여부는 열려 있고 새 로그인 구현은 범위 밖이다. | 이후 설계 단계에서 제안 | AC-003, DEC-001 |

### FLOW-005: 기존 내부 사용자이지만 해당 문서의 허용 대상이 아님

- **지원:** FR-001, FR-004 / AC-001, AC-004의 권한 조건 (AC-003은 직접 적용되지 않음) · OD-005
- **행위자:** 기존 내부 사용자
- **진입 조건:** 로그인 계정은 있으나 해당 문서의 허용 대상 여부가 규칙으로 정해져야 한다.

| 행동 또는 조건 | 관찰 가능한 결과 | 다음 단계 또는 종료 | 요구사항 / 결정 |
| --- | --- | --- | --- |
| 내부 사용자가 문서를 열려 한다. | 허용·거부 여부를 정하는 규칙이 없다. 계정 존재만으로 모든 문서 권한이 있다고 가정하지 않는다. | 규칙 확정 전에는 거부 시 결과를 정의하지 않음 | OD-005, EV-003 |

- **열린 지점:** 허용 대상 규칙과 그 결정 주체는 알려지지 않았다. 문서를 전달하는 행위가 권한 정책을 정할 권한을 뜻한다고 가정하지 않는다.

### FLOW-006: 의도한 리비전을 열 수 없음 또는 열기 실패

- **지원:** 시나리오 5 · GOAL-001 · OD-006
- **행위자:** 기존 내부 수신자
- **진입 조건:** 허용된 수신자가 열려 하지만 의도한 리비전을 사용할 수 없거나 열기가 실패한다.

| 행동 또는 조건 | 관찰 가능한 결과 | 다음 단계 또는 종료 | 요구사항 / 결정 |
| --- | --- | --- | --- |
| 의도한 리비전을 열지 못한다. | 성공 기준을 충족하지 않는다. | 이후 동작은 OD-006 | GOAL-001, OD-006 |
| 다른 리비전을 대신 보여 주는 경우 | 대체본을 성공으로 간주하지 않는다. 대체 허용 여부는 미결정이다. | 열린 상태로 유지 | OD-006 |
| 내용이 비어 있는 경우 | 입력에 정의가 없어 별도 동작을 만들지 않는다. 빈 성공과 실패의 구분이 필요하면 OD-006에서 정한다. | 열린 상태로 유지 | OD-006 |

### 정책 경계 (흐름 미정의)

만료(OD-001), 복사·내보내기(OD-002), 접근 철회(OD-003)는 DEC-002에 따라 미결정이다. 각각 영향받는 분기는 다음과 같다. 현재는 별도 FLOW를 만들지 않는다.
- 접근 가능 기간이 끝난 뒤 열기 → FLOW-001의 진입 조건과 FLOW-006의 결과 (OD-001)
- 사본 생성 이후의 이용 → FLOW-003 (OD-002)
- 철회 후 재접근 → FLOW-001, FLOW-005, FLOW-006의 결과 (OD-003)

해당 정책이 정해지면 영향을 받는 FLOW의 행을 갱신하고 필요하면 새 FLOW 번호를 부여한다.

## 3. 수용 기준 커버리지

| AC | 연결 흐름 | 상태 |
| --- | --- | --- |
| AC-001 | FLOW-001, FLOW-005 | 구조는 정의됨. 기대 리비전은 OD-004, 권한 조건은 OD-005에 막혀 있다. |
| AC-002 | FLOW-002, FLOW-003 | 구조는 정의됨. 기대 리비전은 OD-004에 막혀 있다. |
| AC-003 | FLOW-004 | 정의됨. 차단 안내 방식은 지정하지 않는다. |
| AC-004 | FLOW-001 | 정의됨. 허용 대상 규칙은 OD-005에 의존한다. |

PRD가 아직 만들지 않은 만료, 복사·내보내기, 철회, 열기 실패의 FR/AC는 이 문서도 만들지 않았다. FLOW-006은 PRD 시나리오 5와 OD-006에 연결되며 AC가 없다는 점이 커버리지 공백이다.

비인터랙션: GOAL-001/GOAL-002의 관찰 방법(주간 검토에서 의도한 리비전과 열린 리비전 대조)은 운영상 관찰 제안이며 제품 내 분석 기능 요구가 아니다. 수치 목표나 표본 크기는 정해지지 않았다. [DEC-003]

## 4. 열린 결정과 흐름 영향

| ID | 영향받는 분기 | 차단되는 것 | 진행 가능한 것 |
| --- | --- | --- | --- |
| OD-004 | FLOW-001, FLOW-002 | 기대 리비전과 AC-002의 판정 | 재접근, 대조, 판정 구조 |
| OD-005 | FLOW-001, FLOW-005 | 허용/거부 분기, AC-001·AC-004의 권한 조건 | 익명/외부 차단(FLOW-004) |
| OD-006 | FLOW-006 | 실패, 대체본, 빈 콘텐츠의 결과 | 불일치는 성공이 아니라는 원칙 |
| OD-001 | FLOW-001, FLOW-006 | 기간 만료 후 동작 | 없음(링크 사용 자체도 미확정) |
| OD-002 | FLOW-003 | 사본 통제 | 불일치 관찰 |
| OD-003 | FLOW-001, FLOW-005, FLOW-006 | 철회 후 동작 | 없음 |

결정 주체는 입력에 없으므로 지정하지 않았다.

## 5. 설계 전달 사항

- **탐색 가능:** 수신자가 열린 리비전이 무엇인지 알 수 있는 방법, 차단과 실패 시 안내 표현, 열기 경로. 이 문서는 어떤 시각 요소나 레이아웃도 가정하지 않는다.
- **제품 결정이 필요한 것:** 위 OD-001–OD-006. 특히 OD-004와 OD-005가 정해지기 전에는 성공·실패 분기를 설계로 확정할 수 없다.
- **제약:** DEC-001(기존 내부 사용자만, 새 로그인 구현 없음), DEC-003(의도한 리비전을 여는지로 관찰), DEC-004/005(UI·DB 제안 없음).
- 이 문서는 구현 승인이나 독립 검토 통과가 아니다. 문서 근거는 합성 입력이며 해결책의 효과는 검증되지 않았다. [EV-000]

## 6. 성숙도와 변경 이력

`needs_decision`: 흐름 구조는 모든 AC를 다루지만, 의도한 리비전의 기준(OD-004)과 문서별 허용 대상 규칙(OD-005)이 선언된 핵심 흐름의 결과를 막고 있다. OD-001–OD-003과 OD-006은 해당 분기를 열어 둔 채 남긴다.

| 리비전 | 변경 |
| --- | --- |
| 1 | prd.md revision 1과 원자료로 신규 작성. FLOW-001–FLOW-006 추가. 제거되거나 대체된 링크 없음. |
