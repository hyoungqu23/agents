# 개인 독서 노트 사용자 흐름

## 범위와 근거

개인 사용자가 **기존 태그 하나를 정확히 선택하고, 그 태그에 해당하는 저장된 노트만 확인한 뒤 노트를 여는 흐름**을 다룬다. 태그와 노트는 이미 존재한다. 선행 문서는 없으며, 아래 앵커는 원문을 변경하지 않고 이 문서에서 참조하기 위한 위치 표기다.

| 원문 앵커 | 요구사항·제약 | 흐름 반영 |
| --- | --- | --- |
| SRC-001:L2 | 기존 태그를 정확히 선택하고 해당 태그의 저장된 노트만 확인한 뒤 열기 | FLOW-001, FLOW-002 |
| SRC-001:L3–L4 앞부분 | 빈 결과와 조회 실패를 시각적으로 구분하고, 실패 시 다른 태그 선택 가능 | FLOW-001의 빈 결과·실패 분기 |
| SRC-001:L4의 “This is personal use; tags and notes exist.” | 개인 사용이며 태그와 노트는 이미 존재 | 두 흐름의 사용자·진입 조건 |
| SRC-001:L4–L5의 “Do not add” 이후 | 편집, 공유, 신규 인증, 저장소 설계, 속도 목표 제외. 선행 문서 없음 | 범위 제약; 별도 상호작용 없음 |

원문에 FR/AC ID가 없으므로 위 앵커를 사용한다. 태그 선택 방식이나 화면 배치, API·저장 구조는 정하지 않는다.

## FLOW-001 — 태그로 저장된 노트 조회

- **사용자:** 개인 독서 노트 사용자.
- **진입 조건:** 기존 태그를 선택할 수 있다. 태그와 노트가 존재한다는 사실이 모든 태그에 조회 결과가 있음을 뜻하지는 않는다.
- **근거:** SRC-001:L2–L5.

| 단계·행동 또는 조건 | 사용자에게 보이는 결과 | 다음 단계 또는 종료 |
| --- | --- | --- |
| 1. 사용자가 기존 태그 하나를 정확히 선택한다. | 선택한 태그를 기준으로 조회 결과가 구분된다. 유사 태그나 부분 일치 태그로 범위를 넓히지 않는다. | 해당 태그의 저장된 노트 조회 후 2a, 2b, 2c로 분기 |
| 2a. 조회에 성공하고 해당 노트가 있다. | 선택한 태그에 해당하는 저장된 노트만 확인할 수 있다. | 노트를 선택하면 FLOW-002로 이동 |
| 2b. 조회에 성공했지만 해당 노트가 없다. | 해당 태그의 노트가 없다는 빈 결과를 표시한다. 조회 실패와 명확히 구분한다. | 빈 결과 확인으로 이 조회 종료 |
| 2c. 조회에 실패한다. | 조회에 실패했음을 표시한다. 노트가 없다고 단정하거나 빈 결과로 표시하지 않는다. 다른 태그를 선택할 수 있다. | 사용자가 다른 기존 태그를 선택하면 1로 재진입; 선택하지 않으면 실패 상태에서 흐름 종료 |

실패 후 다른 태그를 선택한 경우에도 새로 선택한 태그의 조회 결과에 따라 2a–2c로 분기한다. 자동 재시도나 동일 태그 재시도 정책은 추가하지 않는다.

## FLOW-002 — 조회된 노트 열기

- **사용자:** 개인 독서 노트 사용자.
- **진입 조건:** FLOW-001의 2a에서 선택한 태그의 저장된 노트를 확인한 상태다.
- **근거:** SRC-001:L2.

| 단계·행동 또는 조건 | 사용자에게 보이는 결과 | 다음 단계 또는 종료 |
| --- | --- | --- |
| 1. 사용자가 조회 결과의 노트 하나를 선택해 연다. | 선택한 노트의 내용을 볼 수 있다. | 노트 열기 목적 달성으로 흐름 종료 |

## 검토 상태와 후속 설계

**ready_for_review:** 원문이 요구한 태그별 조회, 노트 열기, 빈 결과와 실패의 구분, 실패 후 다른 태그 선택을 모두 연결했다. 이 범위의 흐름을 막는 미결 정책은 없다. 질문 없이 작성했으며, 새로운 제품 결정이나 가정을 요구사항으로 추가하지 않았다.

선택 조작의 구체적인 형태, 결과 표현과 노트 열기의 화면 전환 방식은 후속 설계에서 탐색할 수 있다. 어떤 표현을 택하더라도 빈 결과와 실패를 구분하고, 실패 후 다른 태그 선택으로 돌아갈 수 있어야 한다. 노트 열기 자체의 실패나 삭제·변경된 노트 처리 규칙은 원문에 없어 이 문서의 보장 범위에 포함하지 않는다. 그러한 상황이 실제 요구사항으로 추가되면 해당 분기를 보완한다.

이 문서는 사용자 흐름 검토용이며 독립 검토 완료, 게이트 통과 또는 구현 승인을 뜻하지 않는다.
