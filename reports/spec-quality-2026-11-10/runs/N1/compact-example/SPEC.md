# 완료 항목 숨기기

## 1. 목표·범위·제약

FR-local. 사용자는 로컬 목록에서 완료 항목을 숨기고 현재 표시 개수를 확인한다. 항목 자체의 편집·삭제·선택은 범위 밖이다.

## 2. 근거와 결정

SRC-001은 [보관된 요청 원문](../sources/request.md) 1–5행이다. 텍스트로 동작이 확정되었다. 이미지나 별도 디자인 파일은 없으며 컴포넌트와 상태 관리 방식은 구현자 재량이다.

## 3. 화면·흐름

첫 진입과 새로고침 시 체크박스는 해제 상태다. 체크하면 입력 순서대로 done=false인 항목만 표시한다. 해제하면 원래 순서를 복구한다. 표시 개수는 매번 보이는 항목 수다.

## 4. UI 규칙

레이블은 정확히 `완료 항목 숨기기`다. 키보드 focus를 표시하고 실제 Space로 토글할 수 있어야 한다. 기존 blue 토큰 `--accent`를 사용한다.

## 5. 데이터

읽기 전용 props는 (a, Alpha, false), (b, Beta, true), (c, Gamma, false) 순서의 id·label·done이다. 원본을 변경하지 않는다. 요청 2–3행에서 서버/API·권한·저장·로딩·오류 단계와 영속화를 제외했다.
