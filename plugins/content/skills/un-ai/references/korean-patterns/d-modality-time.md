# D. 서법, 확신과 시간

이 파일은 `D` 범주의 상세 규칙만 담는다. [한국어 기본 원칙](../korean.md)으로 먼저 진단한 뒤, 가능성·의무·전망·시제의 강도나 시간 관계가 흔들릴 때 읽는다. 단어 하나만 보고 자동 치환하지 말고 문서 전체에서의 기능과 반복 양상을 확인한다.

각 항목의 **수정 조건**과 **보존 조건**을 함께 적용한다. 고유명사, 숫자, 날짜, 단위, 직접 인용, 법조문, 코드, 명령어, 식별자, 표준 약어는 보호한다. 수정 뒤에는 뜻, 주장 강도, 책임 주체, 높임 수준을 원문과 대조한다.

### D1. “~할 수 있다”가 가능성·능력·허가를 뒤섞음 — 조건부

- **신호:** 기능 설명과 전망이 모두 같은 가능 표현으로 끝난다.
- **수정 조건:** 실제 능력, 선택 가능성, 법적 허가, 불확실한 전망 중 하나로 좁힐 수 있을 때.
- **보존 조건:** 가능성 자체가 주장 내용이거나 단정할 근거가 없을 때.
- **수정 후보:** 단정으로 바꾸기 전에 무엇이 보장되는지 확인한다.

### D2. “예상된다/기대된다/판단된다”의 근거가 없음 — 조건부

- **신호:** 전망의 주체·자료·조건 없이 문장을 안전하게 흐린다.
- **수정 조건:** 원문에서 근거와 판단자를 확인할 수 있거나 표현을 지워도 주장 범위가 같을 때.
- **보존 조건:** 보고서의 공식 전망, 계획의 기대효과, 관찰자의 신중한 판단을 나타낼 때.
- **수정 후보:** 근거를 연결하거나 판단 주체를 밝힌다. 출처가 없으면 출처를 발명하지 않는다.

### D3. 완곡 표현이 겹쳐 의미가 희미함 — 높음

- **신호:** 가능·추측·판단 표지가 한 문장에 두세 겹 붙는다.
- **수정 조건:** 하나의 표지만으로 같은 불확실성을 보존할 수 있을 때.
- **보존 조건:** 각 표지가 서로 다른 층위의 조건을 나타낼 때.
- **수정 후보:** 가장 정확한 한 단계만 남긴다. 단정문으로 뛰어넘지 않는다.

### D4. 당위 종결이 단락마다 반복됨 — 관찰

- **신호:** 여러 단락이 모두 `~해야 한다`, `~할 필요가 있다`로 닫힌다.
- **수정 조건:** 같은 제언을 되풀이하거나 결론이 내용 대신 의무감만 남길 때.
- **보존 조건:** 규정, 안전 절차, 정책 권고처럼 의무가 문서의 핵심일 때.
- **수정 후보:** 일부를 근거·조건·담당 주체 가까이 옮기되 의무의 총량과 강도를 바꾸지 않는다.

### D5. 편집 중 가능성이 사실로 바뀜 — 높음

- **신호:** `~일 수 있다`가 `~이다`로, `관련이 있다`가 `원인이다`로 바뀐다.
- **수정 조건:** 없음. 출처가 더 강한 결론을 명시하지 않는 한 되돌린다.
- **보존 조건:** 원문의 유보, 범위, 조건을 그대로 유지한다.
- **수정 후보:** 문장을 간결하게 만들더라도 서법 표지는 남긴다.

### D6. “~고 있다”와 시제 표현이 기계적으로 반복됨 — 조건부

- **신호:** 일반적 사실, 현재 진행, 지속 상태를 모두 진행형으로 표현한다.
- **수정 조건:** 단순 현재나 상태 동사가 더 정확할 때.
- **보존 조건:** 지금 진행 중이라는 시간 정보가 중요할 때.
- **수정 후보:** 시제를 다양화하려는 목적이 아니라 실제 시간 관계에 맞춰 고친다.
