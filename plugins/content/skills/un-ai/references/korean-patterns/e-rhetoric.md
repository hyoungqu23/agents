# E. 연결과 수사 공식

이 파일은 `E` 범주의 상세 규칙만 담는다. [한국어 기본 원칙](../korean.md)으로 먼저 진단한 뒤, 도입, 접속사, 대조, 중요성 선언, 희망적 결말 같은 수사 공식이 내용을 대신할 때 읽는다. 단어 하나만 보고 자동 치환하지 말고 문서 전체에서의 기능과 반복 양상을 확인한다.

각 항목의 **수정 조건**과 **보존 조건**을 함께 적용한다. 고유명사, 숫자, 날짜, 단위, 직접 인용, 법조문, 코드, 명령어, 식별자, 표준 약어는 보호한다. 수정 뒤에는 뜻, 주장 강도, 책임 주체, 높임 수준을 원문과 대조한다.

### E1. 본론을 예고하는 서론 — 조건부

- **신호:** 글을 시작하겠다는 말, 시대가 변한다는 말, 함께 살펴보자는 말이 핵심보다 먼저 나온다.
- **수정 조건:** 배경을 지워도 독자가 문제와 범위를 이해할 수 있을 때.
- **보존 조건:** 사건의 시점, 긴장, 개인적 장면, 문제 정의를 만드는 도입일 때.
- **수정 후보:** 첫 번째 구체적 사실·장면·쟁점에서 시작한다.

### E2. 문두 접속사가 논리 대신 박자를 만듦 — 조건부

- **신호:** `또한`, `더불어`, `나아가`, `한편`, `따라서`, `즉`이 문장마다 등장한다.
- **수정 조건:** 지운 뒤에도 관계가 분명하거나 실제 관계와 접속사가 맞지 않을 때.
- **보존 조건:** 인과, 반전, 예외, 시간 전환을 독자에게 명시해야 할 때.
- **수정 후보:** 정확한 관계를 쓰거나 생략한다. 단순히 다른 접속사로 순환시키지 않는다.

### E3. 결론 라벨이 결론을 대신함 — 조건부

- **신호:** `결론적으로`, `요약하면`, `정리하자면` 뒤에 본문을 반복한다.
- **수정 조건:** 라벨과 반복을 지워도 결말이 성립할 때.
- **보존 조건:** 긴 보고서의 요약, 발표의 구두 안내, 규정된 결론 섹션일 때.
- **수정 후보:** 마지막 구체적 결정·결과·질문으로 끝낸다.

### E4. “X가 아니라 Y”가 통찰을 연출함 — 조건부

- **신호:** 독자가 X라고 생각한다는 근거 없이 Y를 돋보이게 하려고 X를 먼저 부정한다.
- **수정 조건:** Y만 말해도 논지가 온전하고 본문이 X를 실제로 다루지 않을 때.
- **보존 조건:** X가 현실의 오해·대안·범위이며 Y와의 차이가 논증의 핵심일 때.
- **수정 후보:** Y를 직접 말하거나, X와 Y의 차이를 검증 가능한 기준으로 설명한다.

### E5. “X를 넘어 Y로”가 내용 없는 상승 서사를 만듦 — 조건부

- **신호:** 두 개념 사이의 실제 변화 없이 더 큰 가치로 이동한다고 선언한다.
- **수정 조건:** 무엇이 어떻게 달라졌는지 설명되지 않을 때.
- **보존 조건:** 이전 상태와 새 상태가 정의되어 있고 변화가 자료로 뒷받침될 때.
- **수정 후보:** 실제 변경점이나 결과를 직접 쓴다.

### E6. 질문 뒤에 예정된 답을 바로 붙임 — 조건부

- **신호:** 독자에게 생각할 틈이나 정보 구조상의 필요 없이 수사적 질문과 정답이 한 쌍으로 반복된다.
- **수정 조건:** 평서문 하나가 더 빠르고 명확할 때.
- **보존 조건:** 인터뷰, FAQ, 강연, 실제 미해결 문제, 독자 참여가 필요한 문맥일 때.
- **수정 후보:** 답을 직접 쓰거나 질문을 진짜 쟁점으로 확장한다.

### E7. 중요성을 선언하고 근거를 생략함 — 높음

- **신호:** `핵심적`, `획기적`, `본질적`, `큰 의미`, `중요한 역할`이 변화의 크기를 대신한다.
- **수정 조건:** 원문에 실제 결과·비교·기제가 있거나 평가가 없어도 문장이 성립할 때.
- **보존 조건:** 정의된 등급, 공식 평가, 인용된 판단, 글쓴이의 명시적 견해일 때.
- **수정 후보:** 근거가 있으면 그 사실을 앞세우고, 없으면 과장을 덜어 낸다.

### E8. 뒤 문장이 앞 사실의 의미를 다시 칭찬함 — 조건부

- **신호:** `이는 ~를 보여 준다`, `이를 통해 알 수 있다`가 새 추론 없이 앞 문장을 해설한다.
- **수정 조건:** 해설을 지워도 독자가 같은 결론에 도달할 수 있을 때.
- **보존 조건:** 사실에서 결론으로 가는 추론이 복잡하거나 오해 가능성이 있을 때.
- **수정 후보:** 실제 추론 단계를 쓰거나 해설을 삭제한다.

### E9. 막연한 합의와 내부자 연출 — 높음

- **신호:** `많은 전문가`, `대부분의 사람`, `우리가 놓치는 점`, `진짜 핵심`이 출처 없이 권위를 만든다.
- **수정 조건:** 범위와 출처가 없고 문장의 내용만으로도 주장할 수 있을 때.
- **보존 조건:** 조사 대상·자료·관찰 범위가 제시될 때.
- **수정 후보:** 출처를 밝히거나 글쓴이의 판단으로 정확히 귀속한다.

### E10. 어디에나 붙는 희망적 결말 — 조건부

- **신호:** 지속적 관심, 모두의 노력, 밝은 미래, 앞으로의 기대가 새 정보 없이 글을 닫는다.
- **수정 조건:** 구체적 의무·기한·질문·결과를 만들지 않는 의례적 문장일 때.
- **보존 조건:** 실제 약속, 공식 비전, 캠페인 구호, 독자 행동 요청일 때.
- **수정 후보:** 마지막 구체적 내용에서 끝낸다. 원문에 없는 실행 계획을 만들지 않는다.
