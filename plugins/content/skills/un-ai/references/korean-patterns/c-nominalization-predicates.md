# C. 명사화와 약한 서술어

이 파일은 `C` 범주의 상세 규칙만 담는다. [한국어 기본 원칙](../korean.md)으로 먼저 진단한 뒤, 명사화, 약한 서술어, 유의어 순환 때문에 행동과 개념 경계가 흐릴 때 읽는다. 단어 하나만 보고 자동 치환하지 말고 문서 전체에서의 기능과 반복 양상을 확인한다.

각 항목의 **수정 조건**과 **보존 조건**을 함께 적용한다. 고유명사, 숫자, 날짜, 단위, 직접 인용, 법조문, 코드, 명령어, 식별자, 표준 약어는 보호한다. 수정 뒤에는 뜻, 주장 강도, 책임 주체, 높임 수준을 원문과 대조한다.

### C1. 추상명사가 연속되어 행동이 사라짐 — 높음

- **신호:** `효율성 향상 방안 마련`, `가치 창출 역량 강화`처럼 명사가 여러 겹 쌓인다.
- **수정 조건:** 누가 무엇을 하고 무엇이 달라지는지 원문에서 확인할 수 있을 때.
- **보존 조건:** 제목, 표의 항목명, 행정·학술 개념처럼 명사형이 검색과 분류에 필요할 때.
- **수정 후보:** 핵심 행동 하나를 동사로 돌리고 나머지 개념어는 보존한다.

### C2. “가지고 있다/보유하고 있다”가 특성을 우회함 — 조건부

- **신호:** 성질이나 상태를 `명사 + 가지고 있다`로 길게 표현한다.
- **수정 조건:** `있다`, 형용사, 구체 동사로 정확히 줄일 수 있을 때.
- **보존 조건:** 실제 소유·보유가 법적 또는 물리적 의미를 가질 때.
- **수정 후보:** `높은 확장성을 가지고 있다` → `확장성이 높다`. `특허를 보유한다`는 의미가 다르므로 유지한다.

### C3. “역할을 하다/기여하다/영향을 미치다”가 결과를 대신함 — 조건부

- **신호:** 무엇이 어떻게 달라졌는지 없이 긍정적 작용만 선언한다.
- **수정 조건:** 원문에 기제나 결과가 이미 제시되어 있을 때.
- **보존 조건:** 실제 영향의 방향이나 크기를 단정할 근거가 부족해 넓은 관계만 말해야 할 때.
- **수정 후보:** 근거가 있으면 작동 방식으로 바꾸고, 없으면 더 구체적인 효과를 발명하지 않는다.

### C4. “것·점·바”가 문장 끝을 겹겹이 감쌈 — 조건부

- **신호:** `~한다는 것이다`, `주목할 점은 ~라는 점이다`, `의미하는 바는`이 반복된다.
- **수정 조건:** 명사 껍질을 벗겨도 강조·대조·정의가 사라지지 않을 때.
- **보존 조건:** 앞의 명제 자체를 화제로 삼거나 여러 항목 중 특정 측면을 지목할 때.
- **수정 후보:** 직접 종결을 검토하되 `것이다` 자체를 금지하지 않는다.

### C5. “~할 필요가 있다”가 주체와 의무를 흐림 — 조건부

- **신호:** 권고·의무·선택을 구분하지 않고 같은 표현으로 마무리한다.
- **수정 조건:** 누가 무엇을 해야 하는지와 강도가 원문에 분명할 때.
- **보존 조건:** 행위 주체를 일반화해야 하거나 강한 의무로 올리면 안 될 때.
- **수정 후보:** `검토해야 한다`, `검토하자`, `운영팀이 검토한다`는 서로 다른 서법이다. 원문의 힘과 일치하는 것만 고른다.

### C6. “-적·-성·-화”가 개념을 뭉개는 사슬 — 조건부

- **신호:** 접미사가 겹쳐 실제 대상과 행동을 찾기 어렵다.
- **수정 조건:** 같은 뜻을 더 구체적인 명사·동사로 말할 수 있을 때.
- **보존 조건:** `안정성`, `선형화`, `구조적 실업`처럼 분야에서 정의된 개념일 때.
- **수정 후보:** 접미사 자체가 아니라 정보 손실 여부를 본다.

### C7. 동의어 이중 수식과 유의어 순환 — 조건부

- **신호:** `중요하고 핵심적인`, `효과적이고 효율적인`처럼 경계가 겹치거나 같은 대상을 문장마다 다른 이름으로 부른다.
- **수정 조건:** 두 말이 같은 판단만 반복하거나 지칭 대상이 흔들릴 때.
- **보존 조건:** 각 단어가 서로 다른 측정 기준·역할·상태를 나타낼 때.
- **수정 후보:** 가장 정확한 용어 하나를 반복한다. 반복을 피하려고 새 유의어를 찾지 않는다.
