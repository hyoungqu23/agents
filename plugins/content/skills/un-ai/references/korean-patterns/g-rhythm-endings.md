# G. 리듬과 종결

이 파일은 `G` 범주의 상세 규칙만 담는다. [한국어 기본 원칙](../korean.md)으로 먼저 진단한 뒤, 종결어미, 문장 길이, 병렬 구성, 문장부호의 반복이 사고의 관계를 평평하게 만들 때 읽는다. 단어 하나만 보고 자동 치환하지 말고 문서 전체에서의 기능과 반복 양상을 확인한다.

각 항목의 **수정 조건**과 **보존 조건**을 함께 적용한다. 고유명사, 숫자, 날짜, 단위, 직접 인용, 법조문, 코드, 명령어, 식별자, 표준 약어는 보호한다. 수정 뒤에는 뜻, 주장 강도, 책임 주체, 높임 수준을 원문과 대조한다.

### G1. 같은 종결어미가 사고의 관계까지 평평하게 만듦 — 관찰

- **신호:** 사실, 이유, 예시, 제언이 모두 같은 길이와 종결로 이어진다.
- **수정 조건:** 단조로움이 내용 관계를 가리고 읽기 어려움을 만들 때.
- **보존 조건:** 공적 안내, 규정, 짧은 보고처럼 일관성이 더 중요한 경우.
- **수정 후보:** 어미를 바꾸기 전에 문장을 합치거나 이유·조건을 가까이 둔다. 시제와 서법은 보존한다.

### G2. 짧은 단정문만 연쇄됨 — 관찰

- **신호:** 문장이 모두 독립된 선언이라 원인·예외·근거의 관계가 사라진다.
- **수정 조건:** 원래 한 생각인 문장을 나눠 놓아 호흡만 세 보일 때.
- **보존 조건:** 발표, 광고, 긴장감 있는 서사, 명령 목록에서 단문이 의도된 경우.
- **수정 후보:** 관련 문장만 연결한다. 긴 문장을 목표로 삼지 않는다.

### G3. 긴 복문만 이어져 중심이 묻힘 — 관찰

- **신호:** 모든 문장이 여러 절을 포함하고 핵심 판단이 끝에서만 나온다.
- **수정 조건:** 독자가 주어와 조건을 다시 읽어야 할 때.
- **보존 조건:** 복잡한 범위와 예외를 한 문장에 보존해야 할 때.
- **수정 후보:** 핵심 주장과 보충 설명을 분리한다. 짧은 문장을 장식처럼 끼워 넣지 않는다.

### G4. 병렬 문구가 의미보다 박자를 앞세움 — 조건부

- **신호:** `묻고, 고치고, 성장한다`처럼 비슷한 길이의 동사·명사가 구호처럼 반복된다.
- **수정 조건:** 항목 사이의 관계와 구체 내용이 없거나 자연스러운 항목 수를 왜곡할 때.
- **보존 조건:** 실제로 동등한 단계·원칙·브랜드 문구일 때.
- **수정 후보:** 원인, 순서, 차이를 드러내거나 불필요한 항목을 뺀다.

### G5. 삼단 구성 자체가 목적이 됨 — 조건부

- **신호:** 근거가 둘이거나 넷인데도 항상 세 가지로 맞춘다.
- **수정 조건:** 한 항목이 다른 둘의 반복·상위 개념·장식일 때.
- **보존 조건:** 실제로 세 개의 독립 기준이나 단계가 있을 때.
- **수정 후보:** 자연스러운 개수를 사용한다. 셋을 피하려고 항목을 합치지도 않는다.

### G6. 문장부호가 드라마를 대신함 — 조건부

- **신호:** 대시, 콜론, 괄호, 말줄임표, 한 문장 단락이 얇은 반전이나 강조마다 반복된다.
- **수정 조건:** 보통 문장으로 써도 정보와 호흡이 같을 때.
- **보존 조건:** 삽입, 정의, 목록, 실제 머뭇거림, 화자의 리듬을 정확히 나타낼 때.
- **수정 후보:** 기능 없는 부호만 없앤다. 다른 부호로 기계적으로 교체하지 않는다.
