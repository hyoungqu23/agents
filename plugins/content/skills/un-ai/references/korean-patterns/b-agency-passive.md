# B. 주어, 행위자와 피동

이 파일은 `B` 범주의 상세 규칙만 담는다. [한국어 기본 원칙](../korean.md)으로 먼저 진단한 뒤, 주체·책임이 모호하거나 피동·사동이 행동을 가릴 때 읽는다. 단어 하나만 보고 자동 치환하지 말고 문서 전체에서의 기능과 반복 양상을 확인한다.

각 항목의 **수정 조건**과 **보존 조건**을 함께 적용한다. 고유명사, 숫자, 날짜, 단위, 직접 인용, 법조문, 코드, 명령어, 식별자, 표준 약어는 보호한다. 수정 뒤에는 뜻, 주장 강도, 책임 주체, 높임 수준을 원문과 대조한다.

### B1. 겹피동과 불필요한 사동·피동 — 높음

- **신호:** `보여지다`, `되어지다`, `쓰여지다`처럼 피동 표지가 겹치거나 자연스러운 자동사를 무겁게 만든다.
- **수정 조건:** 단일 피동이나 능동으로 같은 의미를 정확히 낼 수 있을 때.
- **보존 조건:** 형태가 굳어진 어휘이거나 행위보다 상태 변화가 초점일 때.
- **수정 후보:** 단일 피동을 먼저 검토하고, 책임 주체가 중요할 때만 능동으로 바꾼다.

### B2. “~에 의해”가 책임 주체를 뒤로 숨김 — 조건부

- **신호:** 행위자가 알려져 있고 책임이 중요한데도 피동 수식으로 처리한다.
- **수정 조건:** 누가 결정·승인·작성·삭제했는지가 독자 판단에 필요할 때.
- **보존 조건:** 행위자가 중요하지 않은 과학적 과정, 상태 설명, 시스템 메시지일 때.
- **수정 후보:** `위원회에 의해 승인됐다` → `위원회가 승인했다`. 상태 UI의 `요청이 승인되었습니다`는 그대로 둘 수 있다.

### B3. “진행되다/이루어지다/제공되다”가 행동을 가림 — 조건부

- **신호:** 실제 행동과 주체 대신 넓은 피동 서술어가 반복된다.
- **수정 조건:** 원문에 주체와 구체 행동이 이미 있거나 문맥에서 확실히 복원할 수 있을 때.
- **보존 조건:** 사건의 발생·상태가 초점이고 주체를 밝힐 필요가 없을 때.
- **수정 후보:** 원문에 없는 행위자를 만들어 넣지 않는다. 주체를 모르면 더 정확한 상태 동사를 찾거나 피동을 유지한다.

### B4. 추상명사가 사람처럼 판단하거나 요구함 — 조건부

- **신호:** 기술, 시대, 시장, 데이터, 글이 묻고 믿고 요구하고 약속한다.
- **수정 조건:** 실제 판단자나 책임 기관을 숨기거나 상투적인 의인화일 때.
- **보존 조건:** `보고서가 보여 준다`, `컴파일러가 거부한다`처럼 관습적 축약이 정확하거나 비유가 목소리를 만들 때.
- **수정 후보:** 사람·기관을 밝히거나 `자료에 따르면`, `이 변화 때문에`처럼 관계를 풀어 쓴다.

### B5. 주어 생략 때문에 책임이 흔들림 — 높음

- **신호:** 한 단락에 후보 주체가 둘 이상인데 다음 문장의 행동 주체가 생략된다.
- **수정 조건:** 독자가 승인자, 결정자, 경험자를 다르게 해석할 수 있을 때.
- **보존 조건:** 직전 문장과 같은 주체임이 명백할 때.
- **수정 후보:** 필요한 한 문장에만 주체를 복원한다. 이후 문장마다 반복하지 않는다.

### B6. 영어식 대명사와 지시어 반복 — 조건부

- **신호:** `그는`, `그녀는`, `그들은`, `그것은`, `이것은`이 문맥상 필요 이상 반복된다.
- **수정 조건:** 한국어에서 생략해도 대상이 분명하거나 이름·역할명이 더 자연스러울 때.
- **보존 조건:** 대조, 화제 전환, 서사적 거리, 여러 인물 구분에 필요할 때.
- **수정 후보:** 일부만 생략하거나 역할명으로 바꾼다. 대명사라는 이유만으로 전부 지우지 않는다.

### B7. 복수 표지 “-들”이 영어 복수를 따라감 — 조건부

- **신호:** 이미 복수가 분명한 무정물·추상명사마다 `-들`을 붙인다.
- **수정 조건:** 복수 표지가 없어도 수량·분포가 분명하고 문장이 더 자연스러울 때.
- **보존 조건:** 개별 구성원, 분산 행동, 대비되는 여러 집단을 강조할 때.
- **수정 후보:** 삭제 여부만 판단한다. 원문에 없던 `여러`, `다양한`을 자동으로 넣지 않는다.
