# A. 조사와 관계 표현

이 파일은 `A` 범주의 상세 규칙만 담는다. [한국어 기본 원칙](../korean.md)으로 먼저 진단한 뒤, 조사와 관계 표현이 반복되거나 번역 어순 때문에 논리 관계가 흐릴 때 읽는다. 단어 하나만 보고 자동 치환하지 말고 문서 전체에서의 기능과 반복 양상을 확인한다.

각 항목의 **수정 조건**과 **보존 조건**을 함께 적용한다. 고유명사, 숫자, 날짜, 단위, 직접 인용, 법조문, 코드, 명령어, 식별자, 표준 약어는 보호한다. 수정 뒤에는 뜻, 주장 강도, 책임 주체, 높임 수준을 원문과 대조한다.

### A1. “~에 대해/대한”이 관계를 대신함 — 조건부

- **신호:** 논의·설명·검토·고민의 대상을 거의 모두 “~에 대해”로 연결한다.
- **수정 조건:** 목적어나 주제가 분명하고 직접 조사로 이어도 뜻이 같을 때.
- **보존 조건:** ‘무엇을 둘러싼 정보’라는 범위를 나타내거나, 직접 목적어로 바꾸면 관계가 달라질 때.
- **수정 후보:** `정책에 대해 검토했다` → `정책을 검토했다`. 단순히 모든 `에 대해`를 `을/를`로 바꾸지는 않는다.

### A2. “~을 통해”가 만능 연결어가 됨 — 조건부

- **신호:** 수단, 경로, 원인, 계기, 방법을 구분하지 않고 같은 표현으로 묶는다.
- **수정 조건:** 실제 관계를 더 짧은 조사나 동사로 드러낼 수 있거나 가까운 문장에서 반복될 때.
- **보존 조건:** 매개체나 통과 경로 자체가 중요할 때.
- **수정 후보:** `설문을 통해 확인했다` → `설문으로 확인했다` 또는 `설문한 결과 확인했다`. 근거 없이 결과를 인과로 바꾸지 않는다.

### A3. “~에 있어서/측면에서/관점에서”로 본론을 늦춤 — 조건부

- **신호:** 실제 기준을 제시하지 않으면서 문장 앞부분을 늘인다.
- **수정 조건:** 지운 뒤에도 판단 기준과 뜻이 그대로일 때.
- **보존 조건:** 법률상 관점, 비용 측면, 사용자 관점처럼 비교 축이 실제로 필요할 때.
- **수정 후보:** 기준을 명시하거나 더 직접적인 `에서`, `로 보면`, `기준으로`를 쓴다.

### A4. “~와 관련하여/바탕으로/기반하여”의 관계가 모호함 — 조건부

- **신호:** 주제, 근거, 출처, 원인을 한 표현으로 뭉뚱그린다.
- **수정 조건:** 자료를 읽은 것인지, 규칙을 적용한 것인지, 단순히 주제를 말하는 것인지 구분할 수 있을 때.
- **보존 조건:** 해당 표현이 분야의 정형 용어이거나 근거 관계를 정확히 나타낼 때.
- **수정 후보:** `데이터를 바탕으로 결정했다`를 무조건 줄이지 말고 `데이터를 검토해 결정했다`처럼 실제 행동이 주어진 경우에만 풀어 쓴다.

### A5. 조사 결합이 번역 어순을 드러냄 — 높음

- **신호:** `~에서의`, `~에로의`, `~으로부터의`, `~에의`가 겹치며 수식 관계를 멀리 보낸다.
- **수정 조건:** 절이나 자연스러운 조사 하나로 풀 수 있을 때.
- **보존 조건:** 학술·법률 문맥에서 결합 자체가 개념 관계를 정확히 나타낼 때.
- **수정 후보:** 명사를 연속해서 붙이기보다 행위나 위치를 동사·절로 복원한다.

### A6. “~라는 점에서/것으로 인해”가 명목상의 근거만 만듦 — 조건부

- **신호:** 근거나 원인을 설명하는 듯하지만 앞 문장을 다시 명사화할 뿐이다.
- **수정 조건:** 원인·이유를 바로 연결해도 의미가 같을 때.
- **보존 조건:** 여러 특성 중 하나를 특정하거나 법적 판단 요소를 분리할 때.
- **수정 후보:** `비용이 낮다는 점에서 유리하다`는 비교 기준이 실제로 비용이면 남길 수 있다. 막연한 평가라면 근거를 보강하거나 평가를 덜어 낸다.
