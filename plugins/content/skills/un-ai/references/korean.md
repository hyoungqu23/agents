# 한국어 편집 원칙과 라우팅

한국어 구간에만 적용한다. 이 지침은 글의 출처를 판별하지 않는다. 익숙한 AI 문체와 겹치는 표현을 발견해도 그것만으로 작성 주체를 추정하지 말고, 이 글에서 의미·논리·호흡을 해치는지 판단한다.

## 읽을 자료

- 기본 경로는 이 파일 하나다. 교정, 가벼운 편집, 짧은 문장 수정은 여기서 끝낸다.
- 원문에서 반복되거나 애매한 문제가 실제로 확인됐을 때만 [korean-patterns.md](korean-patterns.md)를 열고, 라우터가 가리키는 A–J 범주만 읽는다. 재작성이나 감사라는 이유만으로 전 범주를 열지 않는다.
- 바꿀지 남길지 애매하거나 기계적 교정이 우려될 때는 [korean-examples.md](korean-examples.md)의 대조 사례를 확인한다.
- 고위험·규제 문서, 제약이 많은 긴 글, 큰 폭의 재구성, 명시적 품질 심사에는 [evaluation.md](evaluation.md)를 사용한다. 그 밖의 작업은 이 파일의 종료 기준으로 점검한다.

## 빠른 기본 경로

1. 사실, 서법, 높임, 고유 표기와 목소리를 잠근다.
2. 뜻을 흐리는 명백한 문법 문제와 정보 없는 수사만 고친다.
3. 상세 진단이 필요한 증상이 남았을 때만 관련 범주 하나를 추가로 읽는다.
4. 원문과 대조해 새 주장이나 더 강한 확신이 생기지 않았는지 확인하고 멈춘다.

## 먼저 잠글 것

수정 전에 다음을 내부적으로 구분한다.

- **내용 불변 요소:** 사실, 주장, 수치, 날짜, 범위, 인과관계, 고유명사, 인용, 법률·정책 문구, 사용자가 요구한 용어
- **서법:** 사실, 추측, 가능성, 의무, 허가, 금지, 바람, 약속 가운데 문장이 무엇을 말하는지
- **관계:** 화자와 독자의 거리, 높임의 정도, 호칭, 해요체·합쇼체·해체·한다체
- **장르:** 대화, 발표문, 에세이, 칼럼, 보고서, 설명서, UI 문구, 홍보문, 학술·법률 문서
- **목소리:** 단호함, 신중함, 구어적 호흡, 유머, 망설임, 반복, 짧은 단문, 의도적인 거침
- **표기:** 제품명, 업계 용어, 영어 혼용, 코드, 명령어, 기호, 브랜드 표기

조사·어미·어순은 고칠 수 있지만, 그 결과 내용 불변 요소나 서법이 달라지면 해당 수정을 되돌린다.

## 한국어 판단 순서

1. 문서 전체를 읽고 장르, 독자, 높임 수준, 지배적인 호흡을 파악한다.
2. 한 표현의 출현 여부보다 반복 밀도와 기능을 본다. 같은 표현이 여러 번 나와도 각기 다른 논리적 역할을 하면 남길 수 있다.
3. 문장 단위 수정 전에 단락의 역할을 확인한다. 단락 구조의 문제를 단어 치환으로 숨기지 않는다.
4. 문법 오류와 문체 선호를 구분한다. 겹피동이나 수식 범위 오류는 적극적으로 고치되, 자연스러운 피동·명사형·생략은 취향만으로 바꾸지 않는다.
5. 가능한 수정 중 의미 이동이 가장 적은 것을 고른다. 삭제, 조사 교체, 동사 환원, 문장 결합·분리, 단락 재배치는 정답이 아니라 후보군이다.
6. 수정 후 원문과 대조해 주장 강도, 책임 주체, 시간 관계, 예외 조건이 그대로인지 확인한다.

## 편집 우선도

상세 패턴은 세 수준으로 다룬다.

- **높음:** 문법이 어색하거나 뜻·책임·수식 범위를 흐리는 문제. 문맥상 특별한 이유가 없으면 고친다.
- **조건부:** 한두 번은 자연스럽지만 반복되거나 근거 없이 쓰일 때 글을 흐리는 문제. 문서 수준에서 판단한다.
- **관찰:** 문장 길이, 종결어미, 문단 모양, 문장부호처럼 분포로만 볼 수 있는 특징. 특정 횟수나 비율을 목표로 조작하지 않는다.

어떤 수준도 AI 작성의 증거가 아니다. 감사 결과에는 `표현 → 이 문맥에서의 문제 → 독자에게 미치는 영향 → 수정 방향`을 적는다.

## 한국어에서 특히 보존할 것

### 주어 생략

한국어는 문맥상 분명한 주어와 목적어를 자연스럽게 생략한다. 영어식으로 모든 문장에 “저는”, “우리는”, “그것은”을 복원하지 않는다. 책임 소재나 대상을 둘 이상으로 읽을 수 있을 때만 주체를 밝힌다.

### 높임과 종결어미

같은 문서 안의 우연한 혼용은 정리하되, 인용·대화·브랜드 문구·화자 전환까지 한 단계로 평탄화하지 않는다. 종결어미를 다양하게 보이게 하려고 사실문을 명사형으로 바꾸거나 가능성을 단정으로 바꾸지 않는다.

### 서법과 불확실성

“~일 수 있다”, “~로 보인다”, “~해야 한다”는 장식이 아니라 주장 종류를 나타낼 수 있다. 겹쳐 쓴 완곡 표현은 줄이되, 근거가 허용하지 않는 확신을 새로 만들지 않는다. 막연한 포부를 구체적 일정이나 약속으로 바꾸지도 않는다.

### 전문용어와 외래어

쉬운 말이 항상 더 정확한 것은 아니다. 독자가 실제로 쓰는 `API`, `토큰`, `파이프라인`, 제품명과 법정 용어는 보존한다. 같은 대상을 가리키는 말을 단조로워 보인다는 이유로 유의어로 돌리지 않는다.

### 살아 있는 구어

대화와 발표문에서는 축약, 짧은 문장, 되풀이, 반문, 머뭇거림이 화자의 호흡을 만든다. 표준 문어체로 정리하기 전에 소리 내어 읽고, 실제 발화에서 어색한 부분만 고친다.

`그래서요`, `근데요`, `그러니까요`처럼 연결어에 붙은 `-요`는 청자와 접촉하고 다음 말로 넘어가는 호흡일 수 있다. 가벼운 편집에서는 이해를 막거나 소리 내어 읽을 때 실제로 걸리지 않는 한 군더더기로 보고 지우지 않는다.

`안 나게` 같은 짧은 부정을 `나지 않게`로 풀어 쓰는 것은 문법 교정이 아니라 말투 변경이다. 대화·발표문을 가볍게 편집할 때는 두 표현의 뜻이 같더라도 원문의 구어형을 보존한다.

## 장르별 기준

| 장르 | 우선할 것 | 함부로 바꾸지 말 것 |
| --- | --- | --- |
| 대화·발표 | 발음하기 쉬운 어순, 호흡, 청자 관계 | 축약, 반문, 짧은 반복, 구어 종결 |
| 에세이·칼럼 | 관점, 장면, 논리의 흐름 | 의도적 여백, 비유, 불규칙한 리듬 |
| 보고서·설명서 | 책임 주체, 조건, 정의, 검색성 | 안정된 용어, 필요한 목록과 요약 |
| UI·상태 문구 | 짧고 오해 없는 행동·상태 | 주체가 불필요한 자연스러운 피동 |
| 홍보·SNS | 승인된 태도, 플랫폼 호흡 | 검증된 슬로건, 이모지, 해시태그 규칙 |
| 학술·법률·정책 | 개념 경계, 인용, 서법, 예외 | 명사화된 전문 개념, 정형 문구, 조항 구조 |

## 피해야 할 기계적 윤문

- 단어 목록에 걸렸다는 이유만으로 모두 삭제하지 않는다.
- 접속사, 부사, 피동, 괄호, 대시, 불릿의 허용 횟수를 정하지 않는다.
- 문단마다 짧은 문장이나 긴 문장을 의무적으로 넣지 않는다.
- 같은 종결어미가 반복된다는 이유로 시제·서법·격식을 바꾸지 않는다.
- “첫째, 둘째, 셋째”를 다른 연결어 세 개로 바꾸는 데 그치지 않는다. 열거 자체가 필요한지 먼저 본다.
- 빈 평가를 원문에 없는 숫자·사례·계획으로 구체화하지 않는다.
- 자연스러움을 만들겠다며 속어, 감탄, 개인 경험, 거친 표현을 새로 넣지 않는다.
- 모든 피동문에 사람 주어를 추가하지 않는다.
- 긴 관형절을 무조건 쪼개지 않는다. 수식 대상이 분명하고 장르에 맞으면 유지한다.

## 문서 수준에서 볼 것

개별 문장이 자연스러워도 다음이 누적되면 전체 글이 기계적으로 보일 수 있다.

- 모든 단락이 요약문으로 시작해 설명 세 문장과 결론 한 문장으로 끝난다.
- 문장 길이와 구문이 거의 같거나, 반대로 짧은 단정문만 연속된다.
- 각 단락에서 같은 접속사·대조 공식·결말 공식을 반복한다.
- 제목, 굵은 글씨, 불릿, 이모지가 정보 구조보다 장식 역할을 한다.
- 같은 대상을 매번 다른 말로 부르거나, 같은 의미를 두세 번 평가한다.
- 본문이 이미 보여 준 내용을 마지막 문단이 다시 칭찬하거나 교훈으로 포장한다.

이때 리듬만 무작위로 바꾸지 않는다. 원인과 결과를 붙이고, 예시는 주장 가까이 옮기고, 병렬이 아닌 항목은 목록에서 풀어내는 식으로 생각의 구조를 먼저 고친다.

## 감사와 수정의 경계

- 사용자가 감사를 요청하면 구체적인 구절과 이유를 보고하고 본문은 고치지 않는다.
- 사용자가 교정만 요청하면 맞춤법·띄어쓰기·명백한 문법 오류를 넘어 목소리와 구조를 재작성하지 않는다.
- 사용자가 “AI 티를 없애 달라”고 해도 저자를 숨기기 위한 기만을 목표로 삼지 않는다. 독자가 더 정확히 이해하도록 문장을 개선한다.
- 이미 자연스럽고 목적에 맞는 글은 그대로 둘 수 있다. 수정량이나 패턴 제거율을 성과로 삼지 않는다.

## 종료 기준

한국어 편집은 다음 조건에서 끝낸다.

- 뜻, 서법, 책임 주체, 높임 수준이 원문과 맞는다.
- 남은 반복과 문체 특징이 장르·목소리·논리에 기여한다.
- 수정본에 새 번역투, 억지 대구, 유의어 순환, 인공적인 종결어미 변주가 생기지 않았다.
- 더 고치면 명확성보다 편집자의 취향이 커진다.
