# Existing gstack browse installation

Use an already available browse executable only when it fits the authorized session
and required capabilities. Inspect its version/help and current tab before using
its supported navigation, snapshot, input and screenshot operations. The dogfood
workflow and result rules live in this bundle; do not load another QA SKILL.md or
require a sibling helper to determine the procedure.

Refresh references after rendering/navigation. Capture to the run evidence folder
and open actual images. Retain command/browser traces and meaningful waits rather
than infer success from a returned ref. Reuse an appropriate existing login only
within the user's permission. Cookie import/profile changes and installing gstack
are not automatic prerequisites. If unavailable, use another available browser or
mark relevant checks blocked. Report unsupported input/recording/network features.
