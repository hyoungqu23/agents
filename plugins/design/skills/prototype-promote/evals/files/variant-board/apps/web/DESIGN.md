# Web app rules

## 팔레트

- `--accent: #185adb`
- `--surface: #f6f8ff`
- `--ink: #182033`
- `--radius-panel: 18px`

## Interaction

Cards have a labeled detail toggle and preserve editable notes. Motion is decorative;
the record should stop rotating when reduced motion is requested.

## Component architecture

Keep page layout separate from reusable interactive controls. Do not delete this
nonvisual convention while documenting tokens.
