# Activity screen brief

Target: `apps/activity`, a new small app with no frontend scaffold or flow document.
An activity screen shows the user's recent records and lets them open one record's
details. Provide a local reset. Records have titles, dates and short notes.

Use these sample records, labeled as sample content:

- Morning walk — September 1 — Took the long route by the river.
- Book club — September 3 — Discussed the first three chapters.
- Weekend project — September 5 — Finished the first working draft.

No visual concept or layout has been chosen. Do not connect live services.
The user wants a standalone HTML comparison with three alternatives.
